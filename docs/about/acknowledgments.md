## Open Source Community

SlicerSEEG builds on the work of many open-source projects:

### 3D Slicer

The foundation platform for medical image analysis. Thanks to the entire Slicer community for creating and maintaining this invaluable tool.

- [slicer.org](https://slicer.org/)
- [GitHub](https://github.com/Slicer/Slicer)

### MONAI

Medical Open Network for AI - providing the deep learning framework for brain segmentation.

- [monai.io](https://monai.io/)
- [GitHub](https://github.com/Project-MONAI/MONAI)

### Scientific Python Ecosystem

- **NumPy** - Fundamental array operations
- **SciPy** - Scientific computing algorithms
- **scikit-learn** - Machine learning utilities
- **scikit-image** - Image processing
- **Pandas** - Data manipulation
- **Matplotlib** - Visualization
- **NetworkX** - Graph analysis

### LightGBM

Efficient gradient boosting framework for confidence analysis.

- [lightgbm.readthedocs.io](https://lightgbm.readthedocs.io/)
